# Generate OpenFeature flag manifest

> [!WARNING]
> This feature is experimental and may change in the future.

The [OpenFeature CLI](https://github.com/open-feature/cli) generates type-safe flag accessors from a flag manifest.

Use `semaphore-cli generate manifest` to build an OpenFeature-compatible flag manifest from your Semaphore configuration.

## Add information to your flags

Add a `metadata` block to each flag you want included in the manifest:

- `defaultValue`: **(mandatory)** Default value of the flag.
- `description`: Description of the flag.

> [!NOTE]
> Flags without `metadata.defaultValue` are excluded from the generated manifest.

```yaml
enableFeatureA:
  variations:
    var_a: false
    var_b: true
  defaultRule:
    variation: var_a
  metadata:
    description: Controls whether Feature A is enabled.
    defaultValue: false

usernameMaxLength:
  variations:
    var_a: 20
    var_b: 30
  defaultRule:
    variation: var_a
  metadata:
    description: Maximum allowed length for usernames.
    defaultValue: 50

# ...
```

## Install the Command Line

See the [installation guide](cli.md) to install `semaphore-cli`.

## Generate the flag manifest

### Option 1: Generate locally with semaphore-cli

```shell
semaphore-cli generate manifest \
  --config="<location_of_your_flag_configuration_file>" \
  --flag_manifest_destination="<destination_of_your_flag_manifest>"
```

| Flag | Description |
|---|---|
| `--flag_manifest_destination` | **(mandatory)** Output path where the generated manifest will be written. |
| `--config` | Location of your configuration file. If omitted, searches for `flags.semaphore.<ext>` (or legacy `flags.goff.<ext>`) in `./`, `/semaphore/`, `/etc/opt/semaphore/`, `/goff/`, and `/etc/opt/goff/`. |
| `--format` | Format of your configuration file (`yaml`, `json`, or `toml`). Default: `yaml`. |

### Example flag manifest

```json
{
  "flags": {
    "enableFeatureA": {
      "flagType": "boolean",
      "defaultValue": false,
      "description": "Controls whether Feature A is enabled."
    },
    "greetingMessage": {
      "flagType": "string",
      "defaultValue": "Hello there!",
      "description": "The message to use for greeting users."
    }
  }
}
```

### Option 2: Use the relay proxy endpoint

If you run the Semaphore relay proxy, fetch the manifest directly from its endpoint instead of generating a local file:

```
GET /openfeature/v0/manifest
```

The response matches the OpenFeature CLI manifest format.

> [!NOTE]
> Flags without `metadata.defaultValue` are excluded from the response, just like local generation.

Pull the manifest directly with the OpenFeature CLI:

```shell
openfeature pull --provider-url http://localhost:1031
```

If authentication is enabled on your relay proxy, pass your API key via the `Authorization: Bearer <key>` header or `--auth-token`:

```shell
openfeature pull --provider-url http://localhost:1031 --auth-token secret-token
```

## Use the OpenFeature CLI to generate the flag accessors

Install the OpenFeature CLI from the [OpenFeature CLI repository](https://github.com/open-feature/cli), then run `generate` against either your local manifest file or the relay proxy URL:

```shell
openfeature generate go
```

> [!NOTE]
> This example targets Go, but React, TypeScript, C#, and other languages are supported. See the [OpenFeature CLI documentation](https://github.com/open-feature/cli).

This generates type-safe flag accessors based on your manifest:

```go
// Code generated by OpenFeature CLI. DO NOT EDIT.
// CLI version: 0.4.1

// Package openfeature contains generated code produced by the OpenFeature CLI.
package openfeature

import (
        "context"
        "fmt"

        "github.com/open-feature/go-sdk/openfeature"
)

// stringer transforms a string to a Stringer
type stringer string

// String implements the fmt.Stringer interface
func (s stringer) String() string {
        return string(s)
}

type (
        evaluationValue[T any]   func(context.Context, openfeature.EvaluationContext) T
        evaluationDetails[T any] func(context.Context, openfeature.EvaluationContext) (openfeature.GenericEvaluationDetails[T], error)
)

var client = openfeature.NewDefaultClient()

// TestFlag returns the value of the "test-flag" feature flag.
// this is a simple feature flag
//
// The flag is a type of boolean and defaults to false.
var TestFlag = struct {
        fmt.Stringer
        // Value returns the value of the [TestFlag] flag.
        Value evaluationValue[bool]

        // ValueWithDetails returns the evaluation details of the [TestFlag] flag
        // and the evaluation error, if any.
        ValueWithDetails evaluationDetails[bool]
}{
        Stringer: stringer("test-flag"),
        Value: func(ctx context.Context, evalCtx openfeature.EvaluationContext) bool {
                return client.Boolean(ctx, "test-flag", false, evalCtx)
        },
        ValueWithDetails: func(ctx context.Context, evalCtx openfeature.EvaluationContext) (openfeature.GenericEvaluationDetails[bool], error) {
                return client.BooleanValueDetails(ctx, "test-flag", false, evalCtx)
        },
}

// TestFlag2 returns the value of the "test-flag2" feature flag.
//
// The flag is a type of boolean and defaults to false.
var TestFlag2 = struct {
        fmt.Stringer
        // Value returns the value of the [TestFlag2] flag.
        Value evaluationValue[bool]

        // ValueWithDetails returns the evaluation details of the [TestFlag2] flag
        // and the evaluation error, if any.
        ValueWithDetails evaluationDetails[bool]
}{
        Stringer: stringer("test-flag2"),
        Value: func(ctx context.Context, evalCtx openfeature.EvaluationContext) bool {
                return client.Boolean(ctx, "test-flag2", false, evalCtx)
        },
        ValueWithDetails: func(ctx context.Context, evalCtx openfeature.EvaluationContext) (openfeature.GenericEvaluationDetails[bool], error) {
                return client.BooleanValueDetails(ctx, "test-flag2", false, evalCtx)
        },
}
```
